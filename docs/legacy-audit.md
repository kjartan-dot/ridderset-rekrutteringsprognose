# Teknisk revisjon av tidligere modell

- Stor Gutenberg HTML-blokk med flere inline script/style-seksjoner. WordPress-transformasjon av operatører har tidligere knekt søk. Arkivet er beholdt urørt.
- 407 yrker med fast lønnssnapshot 2024–2025. Snapshot er ikke API-integrasjon. Ny app gjenbruker bare navn/kode og henter lønn via adapter.
- Bedriftssøk på dagens nettside fungerte ved test 14.11.2026. Nordlaks ga faktiske treff, Nordlaks Havbruk AS kunne velges. Den historiske feilen kunne ikke gjenskapes i dette desktopforsøket.
- Seks WorkLife-slidere startet på 5 og produserte 50/100 ved 0/6 besvart. Rapporten videreførte poengene. Forbehold i tekst fjernet ikke feilen. Ny modell bruker null før bekreftelse, også i eksport.
- Arkivets vekter og risikoterskler var ikke empirisk dokumentert. Ny modell har illustrative delgjennomsnitt, ingen total risikoscore.
- Aktive NAV-utlysninger er ikke koblet til i gammel eller ny testversjon. Dette må ikke vises som null utlysninger.
- Scenarioer er hypotetiske, ikke sannsynlighet for ansettelse. Disse er foreløpig utelatt for å prioritere faktiske kilder og beslutningsgrunnlag.
